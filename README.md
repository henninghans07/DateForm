# DateForm 💕

Eine interaktive „Willst du mit mir auf ein Date gehen?"-Webseite – gebaut mit reinem HTML, CSS und JavaScript.

## Features

- **Flüchtiger Nein-Button**: Der Button flieht bei Hover, Klick und Touch an eine zufällige Position
- **Wachsender Ja-Button**: Mit jedem Nein-Versuch wird der Ja-Button größer
- **4-Schritte-Ablauf**: Frage → Wann? → Was? → Zusammenfassung
- **Niedliches Design**: Pastell/Pink, schwebende Herzchen, sanfte Animationen
- **Responsive**: Funktioniert auf Desktop und Mobilgeräten
